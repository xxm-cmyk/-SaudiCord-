## О проекте

SaudiCord — проект, ориентированный на арабский интерфейс Discord, поддержку направления письма справа налево и настраиваемые плагины.

Проект находится в разработке. Наличие файлов в репозитории не означает, что все функции или установщик готовы к использованию.

## Сборка из исходного кода

Требования: Node.js 22 или новее, pnpm версии из package.json, Git.

~~~bash
git clone https://github.com/xxm-cmyk/-SaudiCord-.git
cd -SaudiCord-
pnpm install --frozen-lockfile
pnpm build
~~~
