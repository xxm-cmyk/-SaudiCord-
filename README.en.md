## About

SaudiCord is an independent derivative focused on an Arabic Discord experience, including right-to-left text support and customizable plugins.

The project is under active development. Files present in the repository do not imply that every feature or installer is ready for use; features will be documented after they are tested.

## Build from source

Requirements: Node.js 22 or newer, pnpm at the version specified in package.json, and Git.

~~~bash
git clone https://github.com/xxm-cmyk/-SaudiCord-.git
cd -SaudiCord-
pnpm install --frozen-lockfile
pnpm build
~~~

Development and verification commands are listed in package.json. Do not run injection or uninstall commands before reviewing their instructions and understanding the backup and restore behavior.
